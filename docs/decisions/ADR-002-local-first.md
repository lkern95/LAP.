# ADR-002: Lokal zuerst

- Status: angenommen
- Entscheidung: Trainingsplan, Fortschritt und importierte Verlaufswerte werden lokal verarbeitet und gespeichert.
- Gründe: Datenschutz und Offline-Nutzbarkeit für eine Einzelperson.
- Folgen: Keine Cloud-Synchronisierung zwischen Geräten im ersten Release. Backups und Wiederherstellung müssen spätere Speicherentscheidungen berücksichtigen.
